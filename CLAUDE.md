# Convenciones de este repositorio

- No agregar comentarios extensos ni explicativos en el código. Solo comentarios mínimos y puntuales donde de verdad aporten (lógica no obvia). Nada de bloques describiendo lo evidente.
- No incluir en ningún archivo, comentario, README ni mensaje de commit ninguna referencia a que el código fue generado, escrito o asistido por una IA o herramienta de IA. Sin firmas, sin "Generated with", sin coautorías, sin atribuciones de ningún tipo.
- Mensajes de commit sobrios estilo Conventional Commits (`feat`, `fix`, `refactor`, `chore`, `test`, `docs`), describiendo solo el cambio, sin coautoría ni menciones de herramientas.
- El código debe verse como escrito por el equipo, en el mismo estilo del proyecto existente.
- Nunca commitear `.env`, `environment.*.local.ts` ni secretos.
- No hacer `git push` sin confirmación explícita.
